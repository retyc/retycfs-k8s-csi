RetycFS Helm charts

Helm repository of the RetycFS CSI driver: ReadWriteMany Kubernetes volumes backed by end-to-end encrypted Retyc storage.

Install

The driver runs privileged mount pods: give it a namespace of its own that allows privileged pods (Pod Security privileged).

kubectl create namespace retycfs-system
kubectl label namespace retycfs-system pod-security.kubernetes.io/enforce=privileged
helm repo add retyc https://retyc.github.io/retycfs-k8s-csi
helm repo update
helm install retycfs-csi retyc/retycfs-csi --namespace retycfs-system \
  --set identity.organizationID=<Retyc organization UUID>

Or from the OCI registry:

helm install retycfs-csi oci://ghcr.io/retyc/charts/retycfs-csi --namespace retycfs-system \
  --set identity.organizationID=<Retyc organization UUID>

An administrator of the organization then approves the driver's machine account in Retyc (Organization > Machines, or retyc machine approve) after comparing its fingerprint.
